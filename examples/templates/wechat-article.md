# 公众号文章模板

> 复制本文件，替换【】内容；生成公众号格式：
> `postforge build wechat-article.md -p wechat -o article.html`

# 【标题：吸引点击，40 字以内】

> 【导语：钩子 + 痛点 + 承诺，2-3 句】

## 引子

【用一个场景/故事/数据开头，让读者代入】

:::quote
【一句金句，放在开头或关键位置增强记忆点】
:::

## 第一部分：【小标题】

【正文段落，多用短句。示例：】

- 【要点 1】
- 【要点 2】
- 【要点 3】

:::divider

## 第二部分：【小标题】

【正文。需要对比时用表格：】

| 【维度】 | 【方案 A】 | 【方案 B】 |
| ------- | ---------- | ---------- |
| 【项目】 | 【A 结果】 | 【B 结果】 |

:::warning 划重点
【本部分最重要的提醒，独立成卡增强记忆】
:::

## 结尾

【总结 + 行动号召（关注/在看/转发/评论引导）】

:::tip 行动清单
- [ ] 【读者现在可以做的第一件事】
- [ ] 【第二件事】
:::
