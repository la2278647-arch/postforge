## 文案 A（发布推荐）

写公众号、知乎、掘金、CSDN、小红书，同一篇 Markdown 一键出稿？

我开源了 **PostForge 帖工坊** —— 开源的 Markdown 多平台排版引擎：

🚀 一条命令，6 个平台富文本直接粘贴发布
🎨 3 套主题（简洁/纸感/深色）+ 代码高亮 + 目录
🔒 本地渲染、零配置、不用登录、不用上传数据

现有排版工具基本只支持公众号还年久失修，这应该是中文创作者最缺的工具了。

仓库：https://github.com/la2278647-arch/postforge
MIT 协议，欢迎 Star 和 PR ❤️
